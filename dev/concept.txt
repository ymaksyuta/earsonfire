Game for fingering training. Starting for woodwind (recorder, clarinet) and looking forward for calimba, guitar, piano, etc.
 
Score is the reference shown to the user (today: a loaded midi file); it is not player input.
 
Player input, once implemented, is:
capture - direct note events, from midi-instruments or sensor emulators (e.g. ESP32);
acoustic - pitch/onset detected from real sound, a fallback when no capture device is available.
 
User can provide one or more input sources based on device capabilities. Neither capture nor acoustic is implemented yet.
 
Gameplay is driven by the score. Program may run in two modes:
waiting for correct user input;
running on desired speed.
 
If capture input is provided, actual (player) state is shown alongside recommended fingering.
 
Display layout is optimized for smartphone.
 
Selection screen:
select file (score, currently midi);
select track;
setup user input (instrument, layout, port, rate) - once capture/acoustic exist.
 
Training screen based on instrument:
score line;
instrument view with recommended (and, later, actual) fingering;
training mode;
training speed.
